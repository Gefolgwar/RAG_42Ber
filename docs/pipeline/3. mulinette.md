Коротка відповідь:

Жоден файл із кодової бази вашого проєкту (src/...) у цьому процесі
безпосередньо НЕ виконується.

У цьому й полягає важлива особливість оцінювання, підкреслена в завданні
(subject.pdf, стор. 16, 17, 20):

"The evaluate command is for your own iteration. The official recall@k used
during the defense is computed by the provided moulinette executable, not by
your code. Your solution must never import or call the moulinette."

Що саме тут запускається і які файли беруть участь?

1.  ./moulinette (або скомпільований бінарник moulinette-ubuntu /
    moulinette-fedora)

      - Це автономний зовнішній скомпільований виконуваний файл (тестова система
        школи 42), яка запускається як окремий незалежний процес в ОС.
      - Вона не імпортує модулі з вашої теки src/.

2.  Вхідний файл студента:
    data/output/search_results/UnansweredQuestions/dataset_docs_public.json

      - Створений вашою попередньою командою (search_dataset).
      - Moulinette зчитує цей JSON і перевіряє:
          - Чи структура відповідає Pydantic-схемі StudentSearchResults.
          - Чи жоден відрізок не перевищує ліміт (--max_context_length 2000).
          - Чи збережено точні шляхи до файлів (file_path).

3.  Файл еталонних відповідей (Ground Truth):
    data/datasets/AnsweredQuestions/dataset_docs_public.json

      - Наданий авторами завдання файл, де для кожного запитання вказано
        справжні джерела (sources) та діапазони символів.

Який модуль у вашому проєкті виконує ТОЧНО ТАКУ САМУ логіку?

Якщо ви хочете перевірити, яка логіка зашита всередині moulinette, подивіться на
файл:

  - src/evaluator.py (разом із CLI-командою src/commands/eval_cmd.py)

Цей файл був написаний студентом як аналог мулінет для локального тестування:

  - Функція overlap_ratio(retrieved, truth) рахує перекриття відрізків тексту:
    \text{IoU} = \frac{\text{довжина перетину}}{\text{довжина еталонного відрізка}} \ge 0.05
  - Функція recall_at_k(...) перевіряє, чи хоча б один із знайдених вами чанків
    у топ-k потрапив у той самий файл і має \ge 5\% перекриття з еталоном.

Якщо замість ./moulinette ви запустите власну команду тестування:

uv run python -m src evaluate \
  --student_search_results_path data/output/search_results/UnansweredQuestions/dataset_docs_public.json \
  --dataset_path data/datasets/AnsweredQuestions/dataset_docs_public.json

тоді виконаються саме ваші файли: src/__main__.py, src/cli.py,
src/commands/eval_cmd.py, src/evaluator.py та src/models.py.

Але сам виклик ./moulinette є суто зовнішнім валідатором, що лише читає
згенеровані JSON-файли.
