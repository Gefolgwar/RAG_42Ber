У правилах 42 (і в цій цитаті зокрема) закладено фундаментальний принцип
оцінювання:

1. Етап 1: Обов'язкова частина (Mandatory) — тільки BM25

Під час перевірки mandatory частини екзаменатор/moulinette запускає стандартні
команди, прописані в VI.7.2:

# 1. Індексація (без жодних прапорців --dense)
uv run python -m src index --max_chunk_size 2000

# 2. Пошук
uv run python -m src search_dataset ...

# 3. Перевірка мулінеткою
./moulinette evaluate_student_search_results ...

На цьому етапі твоя система зобов'язана пройти всі пороги САМА ПО СОБІ лише на
лексичному пошуку (BM25):

  - Recall@5 \ge 80\% на dataset_docs
  - Recall@5 \ge 50\% на dataset_code
  - Час індексації \le 5 хвилин
  - Швидкість пошуку \le 90 секунд на 200 питань
  - Жодних помилок від flake8 та mypy

Якщо система залежить від нейромережі або падає без MiniLM — mandatory
провалюється, і бонуси навіть не відкривають дивитися (оцінка 0 за бонуси
автоматично).

2. Етап 2: Бонусна частина (Bonus) — демонстрація MiniLM та гібриду

Тільки після того, як рев'ювер поставив усі галочки за обов'язкову частину, він
